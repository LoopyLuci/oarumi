# NAME — Oarumi

> **Status:** Cleared for pre-alpha use. Annual re-verification required.

---

## 1. The name

**Oarumi** — pronounced approximately `/oʊ.ɑ.ˈru.mi/` (oh-AH-roo-mee).

## 2. Why this name

Oarumi is an **original coinage**, not a borrowed root. It was produced by a
phonotactic-originality process rather than by translating a concept into
Latin or Greek:

- **Phoneme selection**: only segments that are widespread across language
  families — `/o, a, u, i/`, `/r, m/`, plus the diphthong `/oʊ/`.
- **Syllable shape**: CVV + CVV (`oa-ru-mi`), a shape that is rare enough in
  natural-language lexicons that Oarumi does not read as a word from any one
  family.
- **No morphological decomposition**: it does not parse into meaningful roots
  in any language the maintainers have checked.

The result is a name that *feels* familiar to speakers of many languages
without being borrowed from any of them — which is the same design principle
as the language itself.

## 3. What the name is NOT

- It is not Latin, Greek, Sanskrit, or any other classical root.
- It is not a compound of existing words.
- It is not a respelling of a personal name.
- It does not carry a translated meaning such as "truth" or "light". Meaning
  is carried by the language, not the brand.

## 5. If a conflict appears later

1. **Do not rename unilaterally.** Open an issue tagged `name-conflict`.
2. Assess: is the conflict in the same trademark class? Same geography? Same
   audience? Most incidental matches are not conflicts.
3. If a real conflict exists, the maintainers decide between coexistence,
   a class restriction (e.g., never ship a pharma app), or a rename.
4. A rename requires an ADR superseding ADR-0005 and a full documentation
   sweep (see the rename log pattern in CHANGELOG v0.1.0-alpha.3).

## 6. Pronunciation guidance for users

- English approximation: **oh-AH-roo-mee**
- Stress on the second syllable.
- No consonant clusters; every segment is common across language families.
- Written form is unambiguous: five letters, no diacritics, no case
  sensitivity issues (`Oarumi` / `oarumi`).

## 7. Transliteration policy

The name is a proper noun and is **not translated**. In non-Latin scripts it
is transliterated phonetically:

| Script | Transliteration |
|---|---|
| Arabic | أوارومي |
| Cyrillic | Оаруми |
| Devanagari | ओआरुमी |
| Han (phonetic) | 奥阿鲁米 |
| Hangul | 오아루미 |
| Japanese kana | オアルミ |

These are phonetic approximations, not translations. They should be
reviewed by native speakers before being used in official materials.
