# Glossary

## Project terms

- **Oarumi** — the project name; an original coinage, not a borrowed root.
  See `docs/NAME.md`.
- **NSM** — Natural Semantic Metalanguage. The 65-prime semantic core.
- **Prime** — An irreducible semantic unit (e.g., SOMEONE, GOOD, WANT).
- **Combinator** — A grammatical relation between primes.
- **Pivot** — The intermediate natural language (English) between source and NSM.
- **Tri-modal** — Spoken, signed, tactile as first-class expression channels.
- **Parity contract** — The vector-valued equivalence guarantee for a fallback.
- **Symbolic shield** — The deterministic validator around a neural component.
- **Recovery FSM** — The state machine managing failover and re-entry.
- **Bootstrap** — The one-time download step; not a runtime dependency.
- **Gold output** — Frozen deterministic output used as the parity reference.

## Typology terms

- **Agglutinative** — Words built from discrete affixes, one meaning each.
- **Analytic / isolating** — Little inflection; grammar via word order and free words.
- **Fusional** — Multiple grammatical categories fused into one morpheme.
- **Polysynthetic** — Many morphemes per word, including incorporated nouns.
- **Ergative** — Aligns intransitive subject with transitive object.
- **Accusative** — Aligns transitive and intransitive subjects together.
- **Sprachbund** — Area where unrelated languages converge on shared features.
- **Phonotactics** — The rule system governing permissible sound sequences.

## Standards

- **HamNoSys** — Hamburg Notation System for sign language.
- **SiGML** — XML format for sign language gesture markup.
- **CWASA** — Client-side Web Avatar System for Animgen.
- **SSML** — Speech Synthesis Markup Language.
- **NSM primes** — the 65 semantic primes of the NSM program.
