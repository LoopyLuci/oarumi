# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Scope:** all project spaces — repo, issues, PRs, chat, and any agent-mediated
interaction.

**Reporting:** email the maintainers at conduct@oarumi.com. Reports are
confidential. Maintainers will respond within 5 business days.

**AI agents** are expected to follow the same norms. Agent-generated content
that is abusive, spammy, or misrepresents its authorship will be treated as a
violation attributable to the agent's operator.

**Enforcement ladder:** warning → temporary restriction → permanent ban.
Maintainers document each step in a private log.
